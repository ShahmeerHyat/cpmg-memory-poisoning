# Data sources and licenses

This project uses only public data. Raw downloads are **not** redistributed here (see `data/raw/SOURCES.md` for
exact versions and how to fetch them). The files in `data/interim/` and `data/processed/` contain text from the
sources below, transformed as described in `results/DECISIONS.md`.

| Source | What we use | License | Credit |
|---|---|---|---|
| **AgentPoison** — github.com/AI-secure/AgentPoison @ `7b02e28f` | StrategyQA questions/facts and knowledge-base paragraphs, EHRAgent memory logs, the authors' injection templates and shipped triggers | MIT | Chen, Xiang, Xiao, Song, Li. *AgentPoison: Red-teaming LLM agents via poisoning memory or knowledge bases.* NeurIPS 2024. |
| ↳ StrategyQA (as shipped in AgentPoison) | questions, facts; Wikipedia paragraphs | Wikipedia text: CC BY-SA. StrategyQA: see its original release terms | Geva et al. *Did Aristotle use a laptop? A question answering benchmark with implicit reasoning strategies.* TACL 2021. |
| ↳ EHRAgent logs (as shipped in AgentPoison) | logged question / knowledge / code records | as shipped in the AgentPoison repository; check the original EHRAgent terms before reuse | Shi et al. *EHRAgent: Code empowers large language models for few-shot complex tabular reasoning on electronic health records.* EMNLP 2024. |
| **ASB (Agent Security Bench)** — github.com/agiresearch/ASB @ `544540ff` | memory-poisoning plans from the DPI memory databases; agent configs, tasks and tool lists | MIT | Zhang et al. *Agent Security Bench (ASB).* ICLR 2025. |
| **MemoryGraft** — github.com/Jacobhhy/MemoryGraft @ `82366205` | benign and poisoned experience records (`experience_seeds.json`) | MIT | Srivastava, He. *MemoryGraft: Persistent compromise of LLM agents via poisoned experience retrieval.* arXiv:2512.16962. |
| **memshield-bench** — huggingface.co/datasets/npow/memshield-bench (v1.0.0) | non-AgentPoison entries (its poisoned entries were written by the dataset author) | **CC-BY-SA-4.0** | Pow. *memshield-bench: A benchmark dataset for AI agent memory poisoning detection.* 2026. |
| **NotInject** — huggingface.co/datasets/leolee99/NotInject | benign prompts with trigger words (test only) | MIT | Li, Liu, Zhang, Xiao. *PIGuard: Prompt injection guardrail via mitigating overdefense for free.* ACL 2025. |

Generated by us:
- **ASB clean plans** (`data/interim/asb_clean.jsonl`) were generated by running ASB's clean planning prompt with a
  local Qwen3-8B model (Qwen3 weights: Apache-2.0).

Models used (not redistributed here):
- `microsoft/deberta-v3-base` (MIT) — base model for CPMG and the content-only baseline.
- `leolee99/PIGuard` (MIT) — zero-shot baseline.

## License of the derived data in this repository
Because `data/processed/` mixes the sources above and includes CC-BY-SA-4.0 material (memshield-bench, Wikipedia
text), the derived data files in `data/interim/` and `data/processed/` are shared under **CC-BY-SA-4.0**, with the
attributions above. The MIT-licensed sources' copyright notices are retained by reference to their repositories.
