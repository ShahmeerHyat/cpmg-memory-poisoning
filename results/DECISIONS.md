# Decisions log

Every decision that affects the data, model, or evaluation. Newest at the bottom.

## Data (step 2, approved by the group on 7 Nov 2026)
- D1. **Real public data only.** Sources: ASB, AgentPoison, MemoryGraft, memshield-bench, NotInject. MPBench has no data release (HF `pritamdash/mp-bench` is empty) and was dropped. Details: `data/raw/SOURCES.md`.
- D2. **AgentPoison poisoned records** were produced by applying the authors' injection templates (verbatim, file:line refs in `data/sources/agentpoison_inject.py`) to their shipped StrategyQA/EHR records, with their shipped triggers. Their code was not executed (it needs their retriever checkpoints); the template text was copied exactly. The repo ships no optimised EHR trigger, so EHR reuses the StrategyQA triggers.
- D3. **ASB clean memory** was produced by running ASB's clean planning path with a local Qwen3-8B (llama.cpp): 51 tasks x 5 samples = 250 records (199 unique). The two system messages are joined into one (Qwen3 template limitation). Known confound: ASB poisoned records were generated by gpt-4o-mini, clean ones by Qwen3-8B.
- D4. **Provenance from documented origin** (no per-record metadata exists in any source):
  | Source | channel | authority | parent | Why |
  |---|---|---|---|---|
  | AgentPoison StrategyQA (poisoned, twins, paragraphs) | web | external | kb_retrieval | ReAct agent's Wikipedia knowledge base; poison injected into the same KB |
  | AgentPoison EHR | tool | internal | code_exec | EHRAgent's own logged code-execution experiences |
  | ASB | tool | user | agent_plan | Plan memory written by the agent after a user task; DPI arrives through the user prompt |
  | MemoryGraft | doc | external | setup_script | Experience store written by a setup script from an ingested README |
  | memshield-bench (non-AgentPoison entries) | unknown | unknown | unknown | No origin recorded |
  | NotInject (test only) | chat | user | none | User prompts |
  Age is not recorded anywhere, so every record gets `age=unknown`. A provenance-only classifier is trained and reported as a leak check.

## Dataset construction (step 3)
- D5. **memshield-bench deduplication:** its 699 clean entries copied from AgentPoison (`agentpoison_strategyqa`, `agentpoison_ehr`) are dropped; the AgentPoison originals are used instead.
- D6. **NotInject is test-only** (over-defense / false-rejection set). Its provenance (`chat/user`) appears in no training record, so it is never in training.
- D7. **Levels.** L1 = a real poisoned record as stored (all sources). L2 and L3 are **derived** from AgentPoison (StrategyQA + EHR) only, because only there is the injected span and the trigger known exactly:
  - **L2 (compositional, derived):** the scored memory is the record without the injected span (identical to its clean twin); the injected span is stored as a separate co-retrieved record among the neighbours. Positive = payload fragment among the neighbours; negative = same memory with only clean neighbours. The memory text is identical across the pair, so a memory-only model is at chance on this pair by construction. This tests whether a model uses co-retrieved records; it is not a test of semantic composition.
  - **L3 (dormant, derived):** the scored memory is the full poisoned record (its backdoor is conditional on a trigger); positive = later query contains the trigger; negative = same memory, same question without the trigger. Again identical memory text across the pair.
  - ASB, memshield and MemoryGraft give L1 only: ASB's harmful content is the plan itself, so no fragment of it is benign on its own, and the other two have no known trigger.
- D8. **Query and source fields.** Query = the task/question that retrieves the memory (the same neutral question for poisoned and clean at L1/L2, so the query does not leak the label). Source interaction = the original question/task/request that produced the record (`[none]` for memshield).
- D9. **Neighbours:** 3 per example (CLAUDE.md allows up to 5; 3 keeps inputs within 512 tokens), retrieved by TF-IDF cosine from clean records of the same source and split, excluding the record's own twin.
- D10. **Splits:** grouped (StrategyQA question id; EHR question; ASB agent; memshield pair; MemoryGraft record; StrategyQA paragraph title), 70/15/15 by seeded hash. All L1/L2/L3 variants and twins of a group stay in one split.
- D11. **Held-out family:** `badchain` (BadChain trigger) groups are removed from train and val and appear only in test.
- D12. **ASB imbalance:** in train and val, ASB poisoned records are downsampled per agent to the number of clean ASB records for that agent. Test keeps all.
- D13. **Cross-source test:** a separate CPMG model is trained with ASB removed and evaluated on all ASB records (`test_asb_xsource`).
- D14. **Dataset size (seed 42):** train 6,944 (2,987 pos), val 1,434 (586 pos), test 2,900 (1,534 pos), ASB cross-source test 2,211 (2,012 pos), NotInject 339 (all clean). Full breakdown: `data/processed/stats.json`. 0 groups cross splits; 0 held-out-family records in train/val. One test memory (memshield `bulk_t10`) has identical text to a train memory from a different memshield group (dataset-internal duplicate); left in place and noted.
- D15. **Precision:** transformers 5 loads the DeBERTa-v3 checkpoint in its stored fp16 dtype, which gave NaN loss in the smoke test. Models are now loaded with fp32 master weights and run under bf16 autocast (CLAUDE.md: bf16, not fp16).
- D16. **Memory:** batch 8 x 512 tokens with fp32 master weights ran out of the 8 GB VRAM, so gradient checkpointing is on for all runs (CLAUDE.md hardware rule). Effective batch 16 (8 x grad-accum 2).
